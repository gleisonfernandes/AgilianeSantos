# Site Agiliane Santos — Enfermeira Dermatológica

Site responsivo desenvolvido com:
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3
- Bootstrap Icons

## Estrutura

- `index.html` — página principal
- `style.css` — estilos e responsividade
- `script.js` — menu mobile, ano do rodapé e formulário para WhatsApp
- `hero.jpg` — recorte da imagem enviada para o hero

## Como executar

Abra `index.html` no navegador. O Bootstrap e os ícones são carregados via CDN, portanto a máquina precisa de internet para esses recursos.

## Identidade visual
Conforme visto em conversa alianhado a padrões da logo.
